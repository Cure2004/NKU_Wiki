# 防骗指南

::: info 此部分未完成
:::

省流版：

1. 入学当天会有很多校外人士进入学校售卖商品/推销套餐，一定要提高警惕防止被骗
2. 推销办校园卡的很多套餐都比较坑，如果真想办建议货比三家
3. 校园网/校园卡不是必须要办，学校目前提供了免费的校园网（注意WIFI名是NKU_WLAN不是iNankai）
4. 如果想找学长学姐收二手物品（如二手书），尤其是大额交易时，先确认对方是不是真的本校的；另外建议提前摸清价格防止被宰（二手书价格一般在5-10r不等）
